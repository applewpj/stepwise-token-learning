# README Figures

- `overview.png` is the paper overview figure: token-level loss trajectories,
  learning-time spectra, and spectrum-dominated loss-rate reconstruction along
  the T, D, and M axes.
- `token_learning_events.png` is the paper's representative token-event figure:
  learned, early-learning, late-learning, and unlearned trajectories together
  with their loss derivatives.

Both images are rasterized from the corresponding vector figures in the
camera-ready manuscript for display on GitHub and Hugging Face. They visualize
paper results rather than illustrative or synthetic placeholders.
