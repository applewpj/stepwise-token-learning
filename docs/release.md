# Release Scope and Maintainer Guide

## Public Release Scope

This repository releases:

- the reusable `tokenlearning` analysis package;
- paper-aligned T/D/M and synthetic Mano configurations;
- metadata and integrity manifests for public loss matrices;
- plotting, testing, and release-check utilities;
- optional acquisition paths based on public synthetic data or user-supplied
  checkpoints.

The companion
[Hugging Face dataset](https://huggingface.co/datasets/applewpj/token-learning-spectrum-examples)
hosts the large `losses.npz` matrices.

The release does not include private model architectures, weights, tokenizers,
raw private validation text, training-data composition, experiment registries,
checkpoint paths, or internal training infrastructure.

The T/D/M matrices are analysis artifacts rather than raw language-model
datasets. They preserve aligned token losses and axis values while omitting the
private text-to-row mapping. The synthetic Mano matrix additionally includes
public difficulty and question metadata generated by the synthetic pipeline.

## Known Limitations

- The Hugging Face Dataset Viewer does not natively preview NPZ matrices.
- Public T/D/M rows cannot be mapped back to target-token strings or validation
  text.
- The released matrices reproduce post-checkpoint analysis, not private
  pretraining.
- Per-token sigmoid fits summarize dominant localized transitions; individual
  trajectories may contain noise, multiple changes, or boundary effects.
- Runtime for one-million-token fitting is hardware- and configuration-specific.

## Maintainer Workflow

Install contributor and Hugging Face dependencies:

```bash
pip install -e ".[dev,hf]"
```

Run local checks:

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -q
python tools/check_release.py --fail-on-large-github-files
```

Preview an upload without changing the dataset repository:

```bash
python tools/upload_examples_to_hf.py \
  --repo-id applewpj/token-learning-spectrum-examples \
  --dry-run
```

Upload matrices after reviewing paths, byte sizes, and SHA256 checksums:

```bash
python tools/upload_examples_to_hf.py \
  --repo-id applewpj/token-learning-spectrum-examples
```

Large matrices belong in the Hugging Face dataset repository, not GitHub.
Before publishing a new asset:

1. add its metadata to `examples/manifest.yaml`;
2. verify shape, byte size, axis range, and SHA256;
3. add a paper/config/output mapping to `docs/reproduction.md`;
4. update the Hugging Face dataset card and mirrored manifest;
5. run the release checks and CI;
6. publish an immutable dataset revision or tag when possible.

Do not commit `runs/`, caches, local environments, private checkpoints, or raw
private validation data.
